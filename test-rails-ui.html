DELETE /rails/:railId - Delete Rail

Permanently delete a rail and all its items. This action cannot be undone.

PATCH /rails/:railId/items - Edit Rail Items

Edit rail items: delete, freeze/unfreeze, reorder, or add new items. Send the complete list of items you want the rail to have.

Rail Items

Each row represents an item. Remove items to delete them. Toggle "Locked" to freeze/unfreeze. Drag or change order numbers to reorder. Add new rows for new items.

PATCH /rails/reorder - Reorder Rails

Change the display order of rails. Load current rails, modify order numbers, and save.

Rails Order

Modify the order numbers to change rail positions. Lower numbers appear first. You can also use the up/down buttons.
